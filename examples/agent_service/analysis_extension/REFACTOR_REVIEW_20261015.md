## 自评发现及修复

- 通用来源范围缺少协议必需默认字段：补齐 excludedMembers，并沿用 NO_VALUE 表达来源缺值。
- JSON 行定位不同导致同一指标被误判为不同指标：分开保存来源位置与逻辑指标身份；计算、表格和原值图使用一致身份。
- 多查询的执行/观察/证据 ID 可能重用：按实际连接、上下文和查询会话隔离事实与核验，公式依赖限定到对应查询。
- 多查询同一对象同一指标无法进入表格：保留独立来源列；旧制品仍使用原列标识，避免既有报告投影变化。
